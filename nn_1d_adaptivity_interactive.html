Einschicht-Netz 1D

Ein neuronales Netz mit einer versteckten Schicht lernt per Gradientenabstieg eine Funktion aus verrauschten Punkten. Datensatz, Rauschen und Anzahl der Units lassen sich während des Trainings ändern. Das Netz trainiert dann vom aktuellen Zustand aus weiter.

Experimente

  1. Eine Unit reicht für wenig: H = 1 mit tanh auf sin x. Eine einzelne S-Kurve kann nur eine Stufe erzeugen. Erhöhe H schrittweise und beobachte, wie jede neue Unit einen weiteren Bogen beisteuert.
  2. |x| mit ReLU: Mit H = 2 und ReLU ist |x| = ReLU(x) + ReLU(−x) exakt darstellbar. Die Dreiecke unten im Plot markieren die Knickstellen −b/w.
  3. Umlernen von sin x auf cos x: Trainiere auf sin x, bis die Kurve passt (z. B. „+3000 Schritte“). Klicke dann auf cos x. Das Training hält an und zeigt das sin-Modell auf den cos-Daten als Startzustand (gestrichelt). Mit „Training starten“ beginnt der Gradientenabstieg von genau diesem Zustand aus. Das Netz verschiebt seine vorhandenen Units, statt von vorn zu beginnen. Vergleiche, wie schnell das geht, mit „Gewichte neu“ auf cos x.
  4. Overfitting: σ = 0.4, N = 15, H = 50, Momentum an. Der Trainings-MSE fällt unter σ², die Kurve zappelt durch einzelne Punkte, der MSE zu f steigt.
  5. Extrapolation: Im grauen Bereich außerhalb von [−3, 3] gibt es keine Daten. tanh und Sigmoid laufen dort konstant aus, ReLU läuft linear weiter.
