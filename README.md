# Machine Learning Visualizations

Interactive visualizations for teaching machine learning concepts, developed at AImotion Bavaria (Technische Hochschule Ingolstadt).

## 📐 Mathematical Basics

Foundational mathematical concepts for machine learning and optimization:

- [Convexity Explorer](https://loma-aimotion.github.io/ml_visualizations/convexity_interactive.html) - Interactive exploration of convexity of loss functions

## 📊 Probability Theory

Interactive demonstrations of fundamental probability distributions and concepts:

- [Bernoulli Distribution](https://loma-aimotion.github.io/ml_visualizations/bernoulli-plotly.html) - Interactive Bernoulli distribution visualization
- [Bernoulli Distribution (Bar Chart)](https://loma-aimotion.github.io/ml_visualizations/bernoulli-bar.html) - Alternative bar chart representation
- [Bernoulli Likelihood](https://loma-aimotion.github.io/ml_visualizations/bernoulli-llhood_plotly.html) - Likelihood function visualization
- [Bayesian Bernoulli](https://loma-aimotion.github.io/ml_visualizations/bayesian-bernoulli.html) - Bayesian inference with Bernoulli trials
- [Binomial Distribution](https://loma-aimotion.github.io/ml_visualizations/binomial-dist.html) - Interactive binomial distribution
- [Discrete Uniform Distribution](https://loma-aimotion.github.io/ml_visualizations/discrete-uniform.html) - Discrete uniform distribution visualization
- [Continuous Uniform Distribution](https://loma-aimotion.github.io/ml_visualizations/continuous-uniform.html) - Continuous uniform distribution
- [Parametric Distributions](https://loma-aimotion.github.io/ml_visualizations/parametric-dist-plotly.html) - Exploration of parametric distribution families
- [Entropy and Cross-Entropy](https://loma-aimotion.github.io/ml_visualizations/entropy_interactive.html) - How surprised are we? Compare a true distribution with a model to see entropy, cross-entropy and KL divergence, and draw samples to watch cross-entropy emerge as the model's average loss

## 📈 Statistics

Visualizations for statistical inference and sampling concepts:

- [Sampling Distribution](https://loma-aimotion.github.io/ml_visualizations/sampling-plotly.html) - Interactive sampling demonstration
- [Sampling with Confidence Intervals](https://loma-aimotion.github.io/ml_visualizations/sampling-plotly_CI.html) - Confidence interval construction
- [Sampling (Unknown Variance)](https://loma-aimotion.github.io/ml_visualizations/sampling-plotly_unknown_variance.html) - Sampling when population variance is unknown
- [Central Limit Theorem](https://loma-aimotion.github.io/ml_visualizations/central_limit_theorem.html) - Interactive demonstration of the CLT


## 📉 Basic Machine Learning

Linear and logistic regression, their loss functions and training:

- [Squared Error Explorer](https://loma-aimotion.github.io/ml_visualizations/linreg_loss_interactive.html) - Drag a regression line and see the squared errors, SSE, MSE and RMSE of linear regression
- [Logistic Regression 2D Explorer](https://loma-aimotion.github.io/ml_visualizations/logreg_2d_interactive.html) - Rotatable 3D view of the plane w⊤x, its sigmoid surface and class regions; adjust weights or train with gradient descent and watch cross-entropy loss and accuracy
- [Squared Error vs Likelihood](https://loma-aimotion.github.io/ml_visualizations/logreg_likelihood_interactive.html) - Why logistic regression uses maximum likelihood instead of squared error: compare both losses per data point, along one weight, and under gradient descent
- [Likelihood Explorer 3D](https://loma-aimotion.github.io/ml_visualizations/likelihood_3d_interactive.html) - How likely is the observed data under the model? Rotatable sigmoid surface with per-point probability bars for the observed labels; maximise the likelihood with gradient ascent
- [Logistic Regression 2D](https://loma-aimotion.github.io/ml_visualizations/log_reg2d.html) - Two-dimensional logistic regression
- [Logistic Regression (Bokeh)](https://loma-aimotion.github.io/ml_visualizations/log_reg_bokeh.html) - Interactive logistic regression with Bokeh
- [Logistic Regression with Gradient](https://loma-aimotion.github.io/ml_visualizations/log_reg_bokeh_gradient.html) - Gradient descent for logistic regression
- [Logistic Regression Video](https://loma-aimotion.github.io/ml_visualizations/log_reg_video.html) - Animated logistic regression training

## 📝 About

These visualizations are designed for teaching machine learning, probability theory, and statistics courses at Technische Hochschule Ingolstadt. All interactive visualizations use modern web technologies (Plotly, Bokeh) for responsive, educational experiences.
